# 拾页 PageNote

一款精美的手账应用 —— 拾起生活中的每一页。

基于 Flutter 构建，支持 **Android 手机 / 平板** 与 **Windows** 三端，界面自适应：手机使用底部导航，平板与桌面使用侧边导航栏。

## ✨ 功能

- **时光轴** — 按日期分组浏览全部手账，支持收藏过滤、快捷搜索
- **画布手账编辑器** — 一页手账 = 一张自由画布：文字框、照片、贴纸、胶带、日期/心情/天气组件均为可拖拽、双指缩放旋转的独立图层；支持撤销/重做与图层置顶/置底；时间线卡片、编辑器与分享长图共用同一渲染器，所见即所得
- **手账素材库** — 32 款程序绘制的免抠矢量贴纸（自然/美食/生活/可爱）、6 纹样 × 6 色和纸胶带、9 款纸张纹理 + 8 款纯色 + 5 款柔和渐变，全部离线自绘、零图片资产
- **花样字体** — 霞鹜文楷 / 马善政楷 / 站酷快乐体 3 款开源可商用中文字体（OFL 1.1），文字框级可选
- **照片贴纸化** — 相册照片直接转为画布元素，支持圆形 / 拍立得遮罩与圆角
- **整页版式模板** — 6 套内置模板自带纸张、贴纸预设、文字占位与字体，「今日手账」一键套用并自动填入每日一问；任意手账可另存为模板
- **日历** — 月视图回看每一天，当日心情一目了然，可直达某天补写
- **统计** — 总篇数、连续记录天数、本月篇数、累计字数、近 7 天趋势、心情分布、常用标签排行（心情/天气/活动在画布上自由排版的同时仍参与统计）
- **搜索** — 按标题、正文、标签即时搜索，支持按标签快速浏览
- **个性化** — 浅色 / 深色 / 跟随系统主题，6 种强调色，正文字号调节
- **桌面小组件** — Android 桌面展示连续记录天数、今日是否已写与今日一问，点按直达编辑页
- **WebDAV 自动备份** — 定期把全部手账与图片单向备份到坚果云等网盘，最多保留 10 份，支持从云端恢复
- **快速速记** — 一句话 + 可选图片直接入库并标记「未整理」，稍后在编辑页补充心情 / 标签整理成正式手账

## 🛠 技术栈

| 模块 | 方案 |
| --- | --- |
| 框架 | Flutter 3.x（Material 3） |
| 状态管理 | provider |
| 本地存储 | sqflite（Android）/ sqflite_common_ffi（Windows） |
| 偏好设置 | shared_preferences |
| 图片选择 | file_selector（附件复制到应用目录持久保存） |
| 图表 | 自绘（无第三方图表依赖） |

## 🚀 运行

```bash
flutter pub get

# Windows
flutter run -d windows

# Android（手机 / 平板）
flutter run -d <device-id>
```

发布构建：

```bash
flutter build windows --release
flutter build apk --release
```

## 📁 结构

```
lib/
  app.dart            # 根导航骨架（响应式布局）
  main.dart           # 入口与平台数据库初始化
  models/             # 手账条目、画布元素树、心情/天气、素材库模型
  database/           # SQLite 数据库层
  providers/          # 手账数据与设置的状态管理
  pages/              # 时光 / 日历 / 统计 / 设置 / 画布编辑器 / 搜索
  widgets/            # 卡片、画布渲染器/编辑层、表情选择器、标签编辑器等
  theme/              # Material 3 主题
  utils/              # 日期、附件等工具
fonts/                # OFL 开源中文字体（霞鹜文楷/马善政/快乐体,含许可证）
```
