# 手账编辑器竞品调研报告

- 日期：2026-08-16
- 背景拾页 PageNote v1.2.0 手账编辑功能薄弱，做不出美观的手账页面，调研市面主流 app 的编辑器实现方式
- 资料来源：App Store 官方描述（iTunes API）、少数派深度评测（Mori 手帐、Zinnia）、时光手帐官网、本项目代码分析
- 原始资料：同目录 `all_apps_summary.txt`、`specific_apps.txt`

## 一、市场格局：两类编辑器范式

### A. 自由画布拼贴型（"手账美学"阵营）

代表：时光手帐（35万评分 4.9）、念念手帐（17万 4.7）、微手帐（5.8万 4.75）、手帐达人（4.4万）、BuBu手帐（4.2万）、花花手帐（2.9万）、丫丫手帐、Mori手帐、Zinnia（iPad）

**核心模型：一页手账 = 一张自由画布。** 文字框、图片、贴纸、胶带、手绘笔迹全部是可独立移动/缩放/旋转的图层元素；正文不是"文档流"而只是画布上的一种元素。这是与拾页当前"表单 + 纯文本"模型的根本区别。

六大标配素材体系（各家均有，数量与更新频率即竞争力）：

| 素材 | 说明 | 代表卖点 |
|---|---|---|
| 贴纸 | 免抠 PNG，按主题分类（季节/心情/美食/旅行），插画师联名或原创角色 | 时光手帐"与著名插画师合作"；念念原创角色"小羊咩酱" |
| 胶带 | 半透明和纸胶带，用于固定照片、贴边框 | 时光手帐、Zinnia、Mori 均为核心元素 |
| 背景/信纸 | 纹理、图案、纯色信纸 | 时光手帐"背景可自定义颜色"；手帐达人"精选信纸" |
| 花样字体 | 手写体/花哨体，可逐文字框设置 | 丫丫手帐主打"花样字体"；青橙日记"手写体、花哨体" |
| 画笔 | 涂鸦手绘，支持 Apple Pencil | 手帐达人、BuBu、花花手帐 |
| 文字框 | 多个独立文字块，各自设置字体/颜色/底色 |

降低门槛的三板斧（"素人也能做好看手账"的关键）：

1. **整页模板**：模板 = 完整视觉版式（背景 + 贴纸预设位置 + 文字占位），一键套用后只替换文字。念念/BuBu 强调"三步完成一篇手帐"；时光手帐模板由社区博主持续供给。
2. **智能一键排版**：时光手帐"智能图片手帐——挑选图片，一键排版"，自动生成照片拼贴版式。
3. **社区与内容**：时光手帐本质是内容社区（博主模板、拼贴短视频教程）；微手帐"微宇宙"投稿。素材持续更新是留存与变现（素材会员订阅，念念 ¥18/月）的核心。

个性化方向（近两年趋势）：变色贴纸（时光手帐）、GIF 动态贴纸（微手帐"让手帐动起来"）、人像智能抠图生成自定义贴纸（念念会员、微手帐"素材导入+智能抠图"）、用户自定义素材导入。

### B. 结构化引导型（"记录习惯"阵营）

代表：格志日记（九宫格问答 + 模板库 + 问题库 + 增强版 Markdown）、Daylio / 天天豆（心情+活动图标零文字点击式）、Day One（富文本 Markdown + 自动天气/位置元数据 + 模板）、千结记（一句话时间线）

特点：编辑器刻意弱化装饰，强化"降低写作门槛"——引导提问、格子结构、自动元数据。统计能力强（情绪曲线、活动交叉统计）。

**市场空位：两类能力基本互斥。** 时光手帐没有情绪统计；格志/Daylio 没有版面美学。"既好看又能统计"没有强势玩家——这正是拾页的机会。

## 二、拾页现状与差距（代码结论）

- 编辑器 `lib/pages/editor_page.dart`（771 行）= 固定顺序表单：日期→每日一问→心情→天气→活动→纸张/贴纸→标题→**单个纯文本 TextField**→标签→图片九宫格。
- 贴纸仅 30 个硬编码 emoji，缩放/旋转靠**滑条**而非手势；无图层、无撤销。图片固定在页面底部 104×104 网格，不能自由摆放、裁剪、加边框。模板只复制纯文本骨架（不含纸张/贴纸）。无字体选择。素材库刻意零图片资产（REQ-13 设计决策）。
- `docs/需求清单.md` REQ-13 备注已预判：完整画布版需将编辑器从文本流重构为**元素树模型**。

做不出美观手账的根因按权重排序：

1. **没有自由排版模型**——照片+胶带+贴纸的拼贴构图是手账美学的核心，表单结构下根本无法实现
2. **素材为零**——30 个 emoji vs 竞品数百上千张免抠贴纸/胶带/字体
3. **图片不能当设计元素**——只能做"附件"不能做"版面"
4. **模板不含视觉版式**——竞品模板拿到手就已经好看了
5. 交互细节（滑条、无撤销、无图层）体验粗糙

## 三、建议路线

### 第一阶段：素材升级（不动架构，见效最快）

1. 引入免抠贴纸 + 胶带图片素材包。离线免费定位下可用 CC0/开源素材或自绘 SVG（规避版权成本）；同时支持**用户从相册导入图片做贴纸**（微手帐"素材导入"思路，零版权成本补齐长尾）
2. 花样字体 2–4 款：开源可商用中文字体（如霞鹜文楷等，上线前逐款核对授权），文字框级可选
3. 照片贴纸化：相册图片可转为可摆放元素，提供圆形/拍立得白边等 2–3 种遮罩
4. 纸张增加纯色/柔和渐变底色

### 第二阶段：模板升级 + 交互补课

1. 模板升级为整页版式（纸张 + 贴纸预设 + 文字占位 + 字体），实现"新建→选模板→替换文字"三步成稿
2. 贴纸双指缩放/旋转手势替代滑条；贴纸操作撤销/重做；图层置顶/置底
3. "今日手账模板"：每日一问自动填入模板的文字占位

### 第三阶段：画布编辑器重构（元素树，即 REQ-13 完整版）

1. 页面模型改为：`背景 + 元素列表[文本框 | 图片 | 贴纸 | 胶带 | 笔迹 | 心情/天气/日期组件]`，每个元素含 x/y/w/h/rotation/z/opacity
2. `entries` 新增 `canvas` JSON 列存元素树；旧数据迁移时自动生成等价元素（文本框+图片）
3. 时间线卡片、编辑器、分享长图共用同一套元素树渲染器，保证 WYSIWYG
4. **差异化**：心情/天气/活动保留为结构化"组件元素"——既参与自由排版，又继续供统计页使用，占住"既好看又能统计"的空位
